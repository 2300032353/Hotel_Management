## 🔧 **How to Add Images**

### **Step 1: Prepare Your Images**
1. **Resize images** to recommended dimensions
2. **Optimize for web** (compress to <200KB each)
3. **Use descriptive filenames** (as shown above)

### **Step 2: Replace Placeholder Files**
1. **Delete the placeholder files** in `src/assets/images/`
2. **Add your actual image files** with the exact same names
3. **Ensure proper file extensions** (.jpg, .jpeg, .png)

### **Step 3: Test the Application**
1. **Start the development server**: `npm run dev`
2. **Check the home page** for room images
3. **Verify the background** shows the resort pool image
4. **Test on different screen sizes**
